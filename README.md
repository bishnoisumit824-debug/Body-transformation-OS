# Body-transformation-OS
Single app to track workout,diet,running, calories etc all in one place and get the next schedule

## Install on iPhone

The app is hosted free on GitHub Pages and installs from Safari as a home-screen app (works offline, data stays on your phone).

1. **One-time setup on GitHub:** repo **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Every push to `main` deploys automatically (see the **Actions** tab). The app lives at
   `https://bishnoisumit824-debug.github.io/Body-transformation-OS/`
3. On the iPhone, open that link in **Safari** → tap **Share** → **Add to Home Screen** → **Add**.
4. Open it from the home-screen icon. It runs full-screen and works without internet.

Your data is saved on the phone (inside the app). Use the app's backup/export option now and then so you have a copy.
