# Body-transformation-OS
Single app to track workout,diet,running, calories etc all in one place and get the next schedule

## Install on iPhone

The app is hosted free on GitHub Pages and installs from Safari as a home-screen app (works offline, data stays on your phone).

1. GitHub Pages must be on: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**. After any change to `main`, the site updates within a minute or two.
2. On the iPhone, open `https://bishnoisumit824-debug.github.io/Body-transformation-OS/` in **Safari** → tap **Share** → **Add to Home Screen** → **Add**.
3. Open it from the home-screen icon. It runs full-screen and works without internet.

Your data is saved on the phone (inside the app). Use the app's backup/export option now and then so you have a copy.
